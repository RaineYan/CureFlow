# 历史脚本归档

这里保存从仓库根目录移来的 92 个研究、排障和一次性演示脚本。迁移前逐一检查了已跟踪源码和文档中的文件名/模块名引用；这些脚本没有被其他已跟踪文件直接引用。仍被测试或其他脚本引用的历史入口暂留在根目录，以免破坏现有行为。

这些文件是历史材料，**不是当前桌面产品的启动方式，也不保证能在新路径独立运行**。部分脚本依赖当时的实验输入、私有本机路径或特定执行环境；缺少原始证据时不应伪造文件或把旧实验数字当作当前版本结果。

第一次使用请回到 [根目录 README](../../README.md) 和 [快速开始](../../docs/GETTING_STARTED.md)。当前产品代码从 `desktop/`、`cureflow_app/` 和 `workflow/` 阅读。
