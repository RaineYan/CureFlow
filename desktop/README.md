# CureFlow 桌面版

CureFlow 是一款面向表格数据分析、AI 结论核验和局部恢复的 Windows 桌面软件。普通使用者可以直接安装，无需另行安装 Python、Node.js 或项目源码。

## 一、普通用户如何使用

### 1. 安装

上一轮验证版安装包（不是当前源码的最新构建）：

```text
desktop/release-validation-doubao-model/CureFlow-Setup-0.1.0-x64.exe
```

安装后双击 CureFlow。应用会自动启动内置的本地分析服务；普通用户不需要安装 Python、Node.js 或 npm，也不需要打开命令行。若提示本地服务未就绪，可在应用内点击“重启本地服务”。

此包已在当前 Windows 机器上验证自动启动服务和无密钥 CSV 检查，但其生成时间早于当前前端源码修改，因此不包含此后的界面更新。仍需重新构建，并在另一台干净的 Windows 机器上完成安装、卸载和 XLSX 文件验收后再广泛分发。尚未配置受信任的 Windows 代码签名证书，系统可能显示“未知发布者”；只应安装来源可信的包。

### 2. 先检查文件（不需要 API Key）

选择不超过 5 MB 的 `.csv` 或 `.xlsx` 文件，核对读取到的工作表、行列数、字段与样例，然后点击“确认读取范围并查看本地检查结果”。此流程在本机执行结构、质量与适用的统计检查，不调用云模型，也不会将统计极端值直接认定为错误。发现的具体单元格可在人工复核区查看；只有确认安全修正或提供核实后的值，才生成修正版副本并复测。

图表、方法适用性与更多统计结果默认收在“深入数据分析”中，按需展开。若本地规则没有足够证据，系统会说明不能下什么结论。

### 3. 按需连接 AI 解读

需要 AI 解读和报告时，再选择自己有权使用的真实模型服务：

- OpenAI
- 通义千问（Qwen）
- DeepSeek
- 豆包 · 火山方舟（已选用用户确认开通的 `doubao-seed-2-0-pro-260215`；不再要求重复填写模型 ID）

在连接界面输入自己的 API Key 并验证连接。默认只用于本次会话；Windows 用户也可主动选择使用 DPAPI 加密保存，关闭此选项将删除保存的密钥。选择保存后，重启应用可复用已保存的密钥和模型 ID，无需再次输入，但云调用仍须由用户点击“允许并验证已有密钥”确认。密钥不包含在安装包中，也不应写入报告或审计文件。

点击“使用 AI 解读并生成报告”会确认本次最多 6 次云调用；系统不会在模型之间静默切换。连接失败只影响云端解读，不应阻止本地文件检查。

### 4. 支持的数据与边界

桌面版支持不超过 5 MB 的 `.csv` 和 `.xlsx` 文件。

- CSV：支持 UTF-8 等常见文本编码。
- XLSX：读取所有可见且非空的工作表。
- 每个工作表最多读取 10,000 行数据和 100 列。
- 单工作表会按数据类型和样本条件执行字段识别、完整性、重复值、约束、分布、字段关系和分组差异等适用检查；并非每种数据都运行 IQR。
- 多工作表会比较共有字段、单表字段和表间结构关系，并识别可能的训练集、实验集或候选目标列。
- Excel 公式读取的是文件中最后保存的计算结果。上传前应在 Excel 中重新计算并保存。

CureFlow 会先检查数据是否足以支持所选分析目标。没有足够样本、目标字段、分组字段或时间字段时，系统会明确说明哪些问题无法回答，不会把“工具执行成功”冒充为“得出了可靠结论”。

工作台默认选中“完整探索流程”。切换到关联、分组或趋势等问题后，明确选择的问题决定实际分析流程；报告保留原始列名及你选择的字段角色。即使文件含有营收、成本等经营字段，也不会因此要求提供固定的 2024、2025 两年数据。

## 二、隐私和数据边界

- CSV/XLSX 的读取、结构解析和确定性统计在运行 CureFlow 服务的电脑完成。若通过手机或另一台电脑的局域网链接使用，原文件内容会经局域网传到该电脑；当前链路没有 HTTPS，不适合敏感数据。
- 选择真实云模型后，工作流需要的指标、字段摘要和证据上下文会发送给所选服务商。
- 原始表格不会作为附件发给云模型；通用证据解读仅发送字段名、汇总统计和证据引用，不发送原始行或样例值。字段名和统计值本身仍可能敏感，应先获得相应处理授权。
- 使用真实数据前，应确认你拥有相应的数据处理权限，并遵守所在组织及模型服务商的隐私规定。
- CureFlow 不会把 AI 文本直接当成事实；关键结论仍需通过本地统计结果和证据引用校验。

## 三、开发环境要求

仅开发者从源码运行时需要以下环境：

- Python 3.10 或更高版本：`python --version`
- Node.js 18 或更高版本：`node --version`

在你下载或克隆的源码根目录安装 Python 依赖（下列命令都以该目录为起点）：

```powershell
pip install -r requirements.txt
```

运行完整测试：

```powershell
python -m pytest tests -q
```

上一轮验证包位于 `desktop/release-validation-doubao-model/`。这是当前机器上的旧源码验证产物，不等同于最新界面或已完成公开发行验收。更早的 `desktop/release/` 和 `desktop/release-validation/` 安装包仍保留且不包含顶部数据分析入口。发布前请重新构建、运行测试，并在干净系统上完成安装验收；不要把过往通过数量当成当前版本的验收结果。

## 四、从源码启动桌面版

```powershell
Set-Location desktop
npm install
npm start
```

`npm start` 会构建 React 界面、启动 Electron，并自动启动本地 Python 服务。运行数据保存在当前 Windows 用户的应用数据目录，不写回源码目录。

### 在本机浏览器使用

从源码运行网页和本机后端：

```powershell
Set-Location desktop
npm run dev:web:full
```

打开 `http://127.0.0.1:5173/`。本地文件检查不需要密钥；需要云端解读时，才在**同一台电脑**连接 OpenAI、Qwen、DeepSeek 或豆包。点击“使用 AI 解读并生成报告”会确认本次最多 6 次调用。密钥是否有效，以连接验证结果为准；默认会话密钥在服务关闭后失效，主动加密保存的密钥则按界面设置管理。

选文件时，系统只显示 `.csv` 和 `.xlsx`。如果窗口停在“照片”等不含表格的文件夹，请进入表格所在文件夹；也可以把文件拖到导入框。旧版 `.xls` 需在 Excel 中另存为 `.xlsx`。导入后先检查读取到的工作表、行数和字段，再决定是否调用模型。

如果需要指定其他 Python 解释器，可在当前 PowerShell 会话中设置 `CUREFLOW_PYTHON` 后再启动。

## 五、生成 Windows 安装包

在 Windows 上执行：

```powershell
Set-Location desktop
python -m pip install pyinstaller
npm install
npm run dist:win
```

安装包输出到：

```text
desktop/release/CureFlow-Setup-<版本号>-x64.exe
```

该安装包已经包含本地 Python 后端。接收者不需要安装 Python、Node.js、npm，也不需要源码目录。

## 六、通过局域网链接在手机或其他电脑访问

链接版可供同一 Wi-Fi 或局域网内的可信使用者试用真实文件。运行 CureFlow 的电脑需要保持开机，并在 `desktop` 目录执行：

```powershell
npm run dev:web:lan:full
```

启动输出中的 `Network` 地址就是访问链接，例如 `http://192.168.1.20:5173/`。把该链接发到手机或其他电脑，打开后输入同一终端显示的**本次访问码**。访问码每次启动随机生成，停止服务后失效；不要把它公开。首次启动时，如果 Windows 防火墙询问是否允许访问，只允许“专用网络”。

网页会通过同一个链接访问后端，不再把手机错误地指向 `127.0.0.1`。手机端也保留五个任务入口，可以查看分析、执行链路、幻觉检测、修正复测和报告。

局域网访问者不能使用本机密钥配置入口。链接版需要由运行服务的电脑在启动前通过当前 PowerShell 会话配置相应环境变量和云调用许可；访问者不会看到密钥。该模式只适合可信任的局域网小范围试用：当前没有多用户数据隔离、HTTPS 或正式账号体系，不要上传敏感数据，不要把端口映射到公网。离开当前网络后也不能访问。

## 七、模型环境变量（仅供开发者备用）

本机图形界面的会话密钥输入框是正常使用方式。开发调试或局域网访问时仍可通过当前进程的环境变量提供密钥和本地授权：

- OpenAI：`OPENAI_API_KEY`、`CUREFLOW_ENABLE_OPENAI_LIVE=1`
- Qwen：`QWEN_API_KEY`、`CUREFLOW_ENABLE_QWEN_LIVE=1`
- DeepSeek：`DEEPSEEK_API_KEY`、`CUREFLOW_ENABLE_DEEPSEEK_LIVE=1`
- 豆包 · 火山方舟：`DOUBAO_API_KEY`、`CUREFLOW_ENABLE_DOUBAO_LIVE=1`（模型 ID 须与该密钥实际开通的模型一致）

不要把真实 API Key 写入源码、README、配置文件、测试、截图或聊天记录。

## 八、当前产品边界

- 产品界面只提供真实 Provider，不再把离线确定性 fixture 作为普通用户模型。
- 产品界面不提供内置样例、模拟恢复动画或历史实验数字。恢复计划来自本次上传文件，且明确标为“未执行”；只有生成修正版并重新分析后才展示实际复测结果。内部测试用的样例和冻结证据仍保留，不进入普通用户界面。
- AI 可以解释经过本地工具计算的结果并给出修正建议，但不会自动填造缺失数据，也不能替代领域专家审核。
- “修正与复测”页会显示完整待核对线索总数，可点击页内复核窗口，按类型和字段筛选、逐页查看工作表与单元格、原值及规则原因。统计异常仅是线索，不等于已确认错误。用户可标记“原值正确”、勾选安全修正或填写核实后的值；只生成新副本，不改原件。原值正确标记仅保留在当前页面，不会改变规则总数或写入文件。
- 当前安装包未做商业代码签名；公开大规模分发前应增加证书签名、自动更新和正式隐私条款。
